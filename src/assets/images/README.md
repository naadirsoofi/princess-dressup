# Photorealistic Princess Assets

This directory contains high-quality photorealistic images for the Princess Dress-Up Game.

## Image Requirements
- Hair styles: Professional photography or digital art quality
- Dresses: High-resolution fashion photography
- Accessories: Photorealistic jewelry and crown images
- Background: Castle interior with professional lighting

## Format Standards
- Resolution: Minimum 1024x1024 for character elements
- Format: PNG with transparency for layering
- Quality: Professional photography or AAA game asset quality
- Style: Consistent photorealistic rendering

## Licensing
All images should be royalty-free or properly licensed for commercial use.
